# Follow-ups

Steps only a person can do, each filed as one item that waits on facts: a change merged, a date arrived, a fact stated. A repeat of an open step is folded into it, and an item with no step or proof line gets a warning.

Run it with [Bun](https://bun.sh), a JavaScript runtime, from this folder:

```bash
bun tail.ts
```

It has no dependencies. The facts are written out at the top of the file; change them to see items come due.

`SKILL.md` is a draft skill: instructions you can give your own coding agent so it applies the pattern. The write-up is at [stef.io/patterns/the-humans-tail](https://stef.io/patterns/the-humans-tail).
