# Taste record

A dated record of how a person reacts to design and wording, in their own words. Agents add observations; only the person can promote one to a rule. Each rule says what to use instead and where it is enforced, and open tensions stay open until the person closes them.

Run it with [Bun](https://bun.sh), a JavaScript runtime, from this folder:

```bash
bun record.ts
```

It has no dependencies. The observations, rules and tensions are written out at the top of the file; change who declared a rule to see it refused.

`SKILL.md` is a draft skill: instructions you can give your own coding agent so it applies the pattern. The write-up is at [stef.io/patterns/taste-as-a-record](https://stef.io/patterns/taste-as-a-record).
