# Overnight hunt

The part of an overnight bug hunt that needs no model: a finding must cite a rule or a line, only findings a second agent failed to disprove are filed, and a night that did not run says so.

Run it with [Bun](https://bun.sh), a JavaScript runtime, from this folder:

```bash
bun morning.ts
```

It has no dependencies. The two agents' outputs are written out by hand.

`SKILL.md` is a draft skill: instructions you can give your own coding agent so it applies the pattern. The write-up is at [stef.io/patterns/software-that-hunts-its-own-bugs](https://stef.io/patterns/software-that-hunts-its-own-bugs).
